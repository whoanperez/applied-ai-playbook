# Applied AI Playbook

**[English](#english) · [Español](#español)**

## English

Small, complete AI tools for real work, with a focus on **government and regulated industries**. Each folder holds one tool you can install on your own in about ten minutes, a working example, and a short guide in English and Spanish.

| # | Tool | What it does |
|---|---|---|
| 01 | [**html-deck**](01-html-deck/) | A Claude skill that turns the conversation you already had into a designed, interactive HTML presentation in your brand. It's light enough for Sonnet, and the source sits inside the HTML so the deck can be edited later. |

More tools will be added here, one at a time.

**Principles**
- Every example uses public or fictional data. No client information.
- Figures carry their source. Where a result comes from a single test, the README says so.
- MIT license: use it, adapt it, build on it.
